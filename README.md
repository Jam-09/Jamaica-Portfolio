# Jamaica Atutubo — Portfolio

A responsive, single-page student portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally
1. Extract the `jamaica_atutubo_portfolio` folder.
2. Open `index.html` in a modern web browser.
3. The three mini systems are built into the Projects section; no separate project folders or installs are needed.

## Included sections
- Home
- About
- Skills
- Projects (Task Tracker, Weighted Grade Calculator, IT Basics Quiz)
- Education
- Contact

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with the email address where you want to receive messages.
- The contact form opens the visitor's default email application; it does not send messages through a server.
- Update any details or skill descriptions to match your actual experience.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (make sure `index.html` and the `assets` folder are at the repository root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish your site. Your website URL will appear in the Pages settings.

No build tools, package installation, or external project downloads are required. Google Fonts are loaded online; the site otherwise works as a static website.


The profile image is also embedded directly inside `index.html`, so it remains visible even if you upload only the HTML file. The `assets/profile.jpg` copy is included as well.
